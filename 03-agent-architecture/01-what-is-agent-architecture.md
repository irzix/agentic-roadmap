# What is Agent Architecture?

**Agent Architecture** describes how the different components of an agent are structured and work together to achieve a goal.

A typical agent may include:

- **Model** — Provides reasoning and decision-making.
- **Tools** — Allow the agent to interact with external systems.
- **State** — Keeps track of the current execution.
- **Memory** — Stores information that can be useful across interactions.
- **Context** — Determines what information is available to the model.
- **Orchestration** — Controls how the agent executes and coordinates its work.

The architecture can be as simple as a single agent with a few tools, or as complex as a system of multiple specialized agents.

> **Agent architecture is about how the components of an agent are organized and how they work together.**
